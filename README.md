# StepClean Studio — Modern Landing Page

Landing page modern dan responsif untuk **StepClean Studio**, layanan perawatan dan cuci sepatu (*Shoe Care & Spa*) berbasis di Jakarta Timur.

## 🚀 Fitur Utama
- **Hero Section:** Headline informatif, dual CTA, indikator status operasional *live*, dan poin keunggulan utama.
- **Katalog Layanan & Harga:**
  - Fast Clean (Rp 35.000)
  - Deep Clean (Rp 55.000 — Paling Populer)
  - Leather & Suede Treatment (Rp 85.000)
  - Direct order button ke WhatsApp (`wa.me`) dengan pesan otomatis terisi.
- **Alur Pemesanan:** 3 langkah pemesanan mudah (Booking WA &rarr; Perawatan Khusus &rarr; Pengantaran).
- **Social Proof:** Testimoni pelanggan terverifikasi dengan rating bintang 5.
- **Interaktivitas:** FAQ Accordion dropdown dan floating button WhatsApp responsif.
- **Mobile-First Design:** Tampilan fleksibel dan optimal di semua ukuran layar (Desktop, Tablet, & Smartphone).

## 🛠️ Teknologi yang Digunakan
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS (via CDN)**
- **Google Fonts (Inter)**
- **Heroicons / Inline SVG**

## 💻 Cara Menjalankan
Cukup buka berkas `index.html` langsung di browser favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll), tanpa perlu instalasi dependensi tambahan.
